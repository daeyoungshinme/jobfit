# JobFit

이직 준비를 위한 개인 채용공고/이력서 분석 도구입니다. 여러 구인구직 사이트의 채용공고를 수동으로 등록해 자격요건을 자동 파싱하고, 직무별로 가장 많이 요구되는 스킬을 통계로 확인할 수 있습니다. 이력서를 등록하면 규칙 기반으로 개선 제안을 받고, 등록된 채용공고와의 매칭 점수·부족한 스킬·지원 우선순위를 대시보드에서 확인할 수 있습니다.

## 왜 수동 입력인가요?

사람인/잡코리아/원티드 등 대부분의 구인구직 사이트는 이용약관상 자동 크롤링을 금지합니다. 법적 리스크를 피하기 위해 이 프로젝트는 **채용공고 원문을 사용자가 직접 복사해서 붙여넣는 방식**으로 데이터를 수집합니다. 붙여넣은 원문은 자동으로 자격요건/우대사항 섹션을 구분하고 필요한 기술 스킬을 추출합니다.

## 원문이 복사가 안 될 때 (사람인/잡코리아 복사 잠금 해제)

사람인/잡코리아는 공고 페이지에서 텍스트 드래그 선택 자체를 막아둔 경우가 있습니다. `tools/copy_unlock/`의 브라우저 도구는 **사용자가 그 페이지를 직접 보고 있을 때 선택·복사만 다시 가능하게** 풀어줄 뿐, 페이지를 자동으로 가져오거나 서버에 요청을 보내지 않습니다. 복사한 원문은 여전히 사용자가 직접 골라 아래 [/jobs/new 폼](#사용-흐름)에 붙여넣어야 하므로, 위 "왜 수동 입력인가요?"의 자동 크롤링 금지 원칙과 충돌하지 않습니다.

- **북마클릿 (설치 불필요)**: `tools/copy_unlock/copy-unlock.bookmarklet.txt`의 내용을 복사해 브라우저 즐겨찾기(북마크)의 URL 자리에 붙여넣습니다. 공고 페이지를 연 상태에서 이 즐겨찾기를 클릭하면 그 페이지에서만 즉시 복사가 풀립니다.
- **Tampermonkey 유저스크립트 (자동 적용)**: 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 확장을 설치한 뒤, `tools/copy_unlock/copy-unlock.user.js`를 새 스크립트로 추가합니다. 이후 사람인/잡코리아 공고 페이지를 열면 자동으로 복사가 풀리며, 본문이 늦게 로드되는 페이지에도 재적용됩니다.

그래도 복사가 안 되거나 공고 내용이 아예 이미지로 올라온 경우, 아래 OCR 기능으로 캡처 이미지에서 텍스트를 추출할 수 있습니다.

## 캡처 이미지에서 텍스트 추출 (OCR)

`/jobs/new`의 공고 원문 입력란에서 스크린샷/사진 이미지로 텍스트를 뽑아 채울 수 있습니다. 이미지도 사용자가 직접 캡처·업로드하는 것이므로 자동 크롤링과 무관합니다.

- **사용법**: "이미지에서 텍스트 추출" 버튼으로 파일을 선택하거나, 캡처한 이미지를 클립보드에 복사한 뒤 원문 입력란에 `Ctrl+V`로 바로 붙여넣으면 됩니다.
- **사전 설치 필요**: OCR 엔진으로 [Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki)을 사용합니다. Windows용 설치 프로그램을 내려받아 설치할 때 "Additional language data"에서 **Korean**을 반드시 함께 선택하세요. 설치 후 `pip install -r requirements.txt`로 `pytesseract`가 함께 설치됩니다. Tesseract 설치 시 PATH 등록 옵션을 껐다면 기본 설치 경로(`C:\Program Files\Tesseract-OCR\tesseract.exe`)를 자동으로 찾아 사용합니다.

## 설치 및 실행

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8100
```

또는 `./dev.sh` (Git Bash) 를 실행하면 기존에 떠 있는 서버를 정리하고 재기동까지 한 번에 처리합니다. 포트를 바꾸려면 `PORT=8100 ./dev.sh`처럼 환경변수로 지정하세요.

브라우저에서 http://127.0.0.1:8100 접속 (자동으로 `/jobs`로 이동합니다). 데이터는 프로젝트 루트의 `jobfit.db` (SQLite 파일)에 저장됩니다.

## 사용 흐름

1. **채용공고 등록** (`/jobs/new`): 목표 직무의 채용공고 원문을 붙여넣으면 필수/우대 스킬이 자동 추출됩니다. "스킬 미리보기" 버튼으로 저장 전 확인 가능합니다.
2. **스킬 통계** (`/analysis/skills`): 등록된 공고를 직무별로 집계해 가장 많이 요구되는 스킬 랭킹을 보여줍니다. 이 결과를 취업 준비 가이드로 활용하세요.
3. **이력서 등록** (`/resumes/new`): PDF/DOCX/TXT 파일 업로드 또는 직접 입력(경력/프로젝트/학력/스킬) 중 선택합니다.
4. **이력서 분석** (`/resumes/{id}`): 섹션 누락, 정량적 성과 표현 부족, 액션 동사 부족 등 규칙 기반 개선 제안을 확인합니다.
5. **매칭 대시보드** (`/analysis/dashboard`): 이력서를 선택하면 등록된 채용공고별 매칭 점수와 부족한 스킬이 우선순위 순으로 정렬되어 나타납니다.

## 기술 스킬 사전 커스터마이징

`app/data/skills_dictionary.json` 파일에 카테고리별로 스킬명과 동의어(aliases)를 등록합니다. 기본값은 IT/개발자 직군 위주로 시드되어 있으며, 다른 직군(마케팅, 영업, 디자인 등)을 준비 중이라면 이 파일에 원하는 스킬/역량과 동의어를 추가하면 바로 인식됩니다.

```json
{
  "카테고리명": [
    { "name": "스킬명", "aliases": ["동의어1", "동의어2"] }
  ]
}
```
